AI Workshop DM 개인정보처리방침

시행일: 2026년 10월 29일 · 적용 대상: AI Workshop DM / AI Workshop DM-IG의 운영자 전용 GCP Cloud Run 버전

운영 목적과 연락처

이 프로그램은 Instagram 계정 @ai.journeyman 운영자가 본인 계정의 댓글·메시지 알림 수신과 조건에 따른 자동 응답을 운영하기 위해 사용합니다. 개인정보 관련 문의 및 삭제 요청은 해당 Instagram 계정에 DM으로 보내실 수 있습니다. 요청은 운영자가 직접 확인합니다.

처리하는 정보

관리 화면의 네이버 로그인에서는 네이버가 제공하는 앱별 고유 이용자 식별자를 조회하여 운영자가 승인한 계정인지 확인합니다. 이름·이메일·전화번호 등의 추가 프로필 정보는 권한 판정에 사용하지 않습니다. 승인한 식별자는 접근 허용 목록으로 Secret Manager에 보관합니다. 네이버 접근 토큰은 서버의 프로필 조회에만 사용하고 저장하거나 갱신하지 않으며, 브라우저에는 별도의 만료되는 로그인 세션을 발급합니다. 승인되지 않은 계정에는 관리 정보 접근을 허용하지 않습니다.

계정 연결 확인 시 Instagram 계정 ID와 사용자명을 조회합니다. 운영자가 직접 입력한 액세스 토큰·앱 시크릿·웹훅 인증 토큰은 Google Cloud Secret Manager의 접근 제한된 비밀 설정에 저장합니다. Instagram 비밀번호를 이 프로그램에 입력하거나 저장하지 않습니다.

Meta가 전달한 웹훅 알림에는 댓글·메시지 내용, 사용자명과 사용자 ID, 게시물·댓글·메시지 식별자, 발생 시각, 버튼 클릭 등의 정보가 포함될 수 있습니다. 수신기는 서명 검증을 통과한 이벤트 원문과 수신 시각을 서버 데이터베이스에 저장합니다. 계정에서 구독한 이벤트와 Meta가 실제 전달하는 범위에 따라 포함 정보가 달라집니다.

이용 및 보관

정보는 계정 연결 확인, 알림 수신과 오류 확인, 조건부 자동 응답과 운영에 이용합니다. 운영자가 켠 규칙의 게시물·키워드 조건을 만족하는 새 댓글에 첫 비공개 답장과 버튼을 보냅니다. 팔로우 조건이 있는 규칙은 버튼 클릭 시 Meta API로 팔로우 여부를 조회하고 실제 팔로우가 확인될 때만 후속 메시지를 보냅니다. 팔로우 조건이 없는 규칙은 자료 받기 버튼 클릭 시 후속 메시지를 보냅니다. 미팔로우와 조회 오류는 구분하며 재확인 안내는 60초 간격으로 제한합니다. 설정에 따라 첫 비공개 답장이 성공한 댓글에 공개 대댓글을 한 번 보낼 수 있습니다. 이를 위해 대상 댓글·이용자 식별자, 확인 결과, 발송 상태와 메시지 식별자를 보관하며 중복 발송 방지에도 이용합니다. 꺼진 규칙과 활성화 전 과거 댓글에는 자동 발송하지 않습니다. 규칙을 끄거나 수정하면 기존 버튼의 후속 처리를 중지합니다. 전송 결과가 불확실한 메시지는 자동 재발송하지 않습니다.

시험에 필요한 동안 보관하며, 필요가 없어지거나 본인 확인 후 삭제 요청이 처리되면 운영자가 서버·이전 운영 컴퓨터·관련 백업의 기록을 확인해 삭제합니다. 현재 자동 만료·자동 삭제 기능은 없으며 운영자가 수동으로 관리합니다. 복구 시 삭제 대상이 다시 처리되지 않도록 운영자가 관리합니다.

외부 서비스와 저장 위치

관리자 네이버 로그인 시 인증은 네이버에서 진행되며 인증 코드와 앱 자격정보는 서버에서 HTTPS로 네이버 토큰 API에 전달합니다. 발급된 토큰으로 네이버 프로필 API에서 고유 식별자를 조회합니다. 네이버 인증 코드가 포함된 콜백 요청 URL은 운영 로그 저장 대상에서 제외합니다.

계정 조회 요청과 액세스 토큰은 HTTPS로 Meta의 Instagram API에 전달됩니다. 웹훅 알림은 HTTPS로 Google Cloud Run(서울 리전)에 직접 전달됩니다. 수신한 이벤트·발송 기록·규칙은 Firestore(서울 리전)에, 비밀 설정은 Secret Manager(서울 리전)에 보관합니다. Cloud Tasks(서울 리전)는 원문 대신 이벤트 식별자를 전달해 후속 처리를 요청합니다. 운영 로그에는 요청 시각·응답 상태 등이 포함될 수 있으며 웹훅 인증 토큰이 포함된 검증 요청 URL은 로그 저장에서 제외합니다. 이전 로컬·VM 운영 기록과 이전용 백업은 접근을 제한한 운영자 컴퓨터에도 남아 있습니다. 관리 화면은 인증된 운영자만 접근할 수 있습니다. 외부 분석·광고 또는 AI 모델 전송 기능은 없습니다. Meta와 Google Cloud 자체 서비스의 처리에는 각 서비스의 정책도 적용됩니다.

삭제 요청과 연결 해제

데이터 삭제 안내에 따라 @ai.journeyman으로 요청할 수 있습니다. 앱 연결을 해제해도 서버·이전 운영 컴퓨터·백업에 저장된 기록이 자동 삭제되지는 않으므로 별도로 요청해 주세요. Meta 또는 Instagram 자체에 남는 원본 데이터의 삭제는 해당 서비스에서 별도로 처리해야 합니다.

변경

자동 발송, 외부 이용자 연결, 외부 저장소 또는 새로운 처리 목적을 추가하기 전 실제 구현과 운영 방식에 맞게 이 안내를 갱신합니다.
